# building this project); letting dbt-postgres drive the resolution avoids it.
# Also note: as of late 2025/2026, `pip install dbt-core` alone can pull in
# dbt Labs' newer Rust-based "Fusion" engine, which does not yet support
# Postgres -- installing dbt-postgres explicitly (as below) avoids that trap.
